# بوابة فرع سوهاج للتأمين الصحي (Sohag Health Insurance Portals)

تم تقسيم المشروع إلى **تطبيقين ويب تقدميين (2 PWA Applications)** مستقلين تماماً لتلبية متطلبات الخصوصية وسهولة الاستخدام:

---

## 1. تطبيق حجز العيادات للمنتفعين والمواطنين (`booking-app/`)
* **الهدف:** تطبيق مخصص ومبسط حصرياً لجمهور المواطنين والمنتفعين لحجز مواعيد عيادات التأمين الصحي بسوهاج.
* **الرابط المدمج:** `https://reserv.hiocdis.org/hioClinicReservation.aspx`
* **المميزات:**
  - واجهة سريعة باللغة العربية متوافقة تماماً مع شاشات الهواتف المحمولة وكبار السن.
  - إرشادات وخطوات الحجز بالرقم القومي والأوراق المطلوبة.
  - دعم التثبيت المباشر كتطبيق على شاشة الهاتف (PWA).
  - أرقام الدعم والخط الساخن (106 / 15335).

---

## 2. بوابة المنظومات المركزية للموظفين والإدارة (`staff-portal/`)
* **الهدف:** لوحة تحكم إدارية وطبية موحدة تجمع **23 منظومة وسيرفر** حكومي ومحلي.
* **الأقسام:**
  1. اللجان الطبية والمجالس المتخصصة (6 منظومات: Psycho, لجان التأمين، الفحص الشامل، RPD, SMA, كشف الحج).
  2. التخصصات والمبادرات الرئاسية (5 منظومات: الأورام، السكر، هرمون النمو، فحص الأنيميا 2024، معامل الطلاب).
  3. المخازن والمالية والإدارة (5 منظومات: المخازن IP، مخازن التأمين، الشراء الموحد UPA، إدارة HIO Admin، المنظومة المالية FRM).
  4. خدمات المنتفعين والطلاب والسيرفرات (6 منظومات: حجز مركزي، سيرفر الحجز الداخلي، HioRequest، بوابة المنتفعين IP، تأمين الطلاب، مقدمي الخدمة).
  5. التواصل الإداري السريع (واتساب ويب للإدارة).
* **المميزات:**
  - **نظام الفتح الذكي (Smart Launcher):** فتح المنظومات في نوافذ تطبيق مدمجة مستقلة بدون أشرطة متصفح مشتتة.
  - **تجاوز قيود SSL و Mixed Content:** دليل وإشعار للمستخدمين لكيفية تجاوز شاشة التحذير في السيرفرات التي تعمل بـ IP مباشر.
  - **البحث والفلترة اللحظية:** حسب الاسم أو الرابط أو القسم.
  - **المفضلة والتثبيت:** تثبيت المنظومات الأكثر استخداماً في أعلى اللوحة مع الحفظ التلقائي في `localStorage`.
  - **إضافة وتعديل الروابط:** إمكانية تعديل مسار رابط الأنيميا أو إضافة سيرفرات مخصصة جديدة وحفظها محلياً.
  - **دعم التثبيت (PWA Ready):** تثبيت البوابة كتطبيق مستقل على أجهزة الكمبيوتر والموبايل.

## طريقة التشغيل المحلي (Local Development)

### لتشغيل تطبيق حجز المنتفعين:
```bash
cd booking-app
npm install
npm run dev
```
سيعمل التطبيق على الرابط: `http://localhost:3001`

### لتشغيل بوابة الموظفين الموحدة:
```bash
cd staff-portal
npm install
npm run dev
```
سيعمل التطبيق على الرابط: `http://localhost:3000`

---

## طريقة الرفع المباشر على استضافة Vercel

1. ارفع الكود على مستودع GitHub (مثلاً: `sohag-hio-portals`).
2. افتح حسابك على [Vercel](https://vercel.com) واضغط **Add New Project**.
3. **لرفع تطبيق المنتفعين:**
   - اختر المستودع.
   - في خانة **Root Directory** اختر مجلد `booking-app`.
   - اضغط **Deploy**.
4. **لرفع بوابة الموظفين:**
   - اضغط **Add New Project** مرة أخرى واختر نفس المستودع.
   - في خانة **Root Directory** اختر مجلد `staff-portal`.
   - اضغط **Deploy**.
